How It Works

From signal to response in four steps

NightWatch Sentinel captures browser signals, scores threats, generates AI playbooks, and relays events — all in one unified pipeline.

01

Capture

Run modular analyzers across permissions, device surface, network state, Bluetooth, and URL heuristics.

02

Score

All findings are normalized through a severity-weighted risk engine producing a 0–100 composite score.

03

Respond

Gemini AI transforms the threat context into actionable containment and hardening playbooks.

04

Relay

Push structured events into downstream systems through the built-in API buffer and event pipeline.
